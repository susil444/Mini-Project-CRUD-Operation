# Mini-Project-CRUD-Operation

A web-based mini project developed using Java, Spring Boot, and MySQL that performs complete CRUD (Create, Read, Update, Delete) operations to manage employee records efficiently.

🚀 Tech Stack

Backend: Java with Spring Boot

Database: MySQL

Frontend: HTML, CSS

Build Tool: Maven

Architecture: MVC (Model-View-Controller)

✨ Key Features

➕ Add New Employee

📋 View All Employees

🔍 View Employee by ID

✏ Update Employee Details

❌ Delete Employee Record

🗄 Database Integration with JPA/Hibernate

📂 Project Structure

controller – Handles HTTP requests

service – Business logic layer
repository – Database interaction using JPA

model – Entity classes

repository – Database interaction using JPA

model – Entity classes
